# 知乎模式

用于把知识库内容改成知乎回答或文章。知乎适配只改变阅读节奏，不改变个人风格内核和事实标准。

## 推荐结构

1. 开头直接回答问题，说明读者能得到什么。
2. 先建立必要认知，再解释容易混淆的概念。
3. 用真实场景、对比或最短步骤帮助理解。
4. 给出可执行的方法、提示词或检查清单。
5. 结尾停在核心判断、流程或行动建议上。

## 写法

- 每段尽量短，避免手机端出现大块文字墙。
- 标题帮助跳读，不使用夸张悬念。
- 观点可以鲜明，但要与事实分开。
- 专业内容先讲结论，再补原因。
- 案例必须真实或明确标为示例。
- 引用只支撑关键事实，不用链接堆砌制造专业感。

## 禁止

- 编造“我曾经”“我的朋友”等经历。
- 使用震惊体、成功学口号或无依据的绝对结论。
- 把社区热度当作事实正确性。
- 为了互动而添加“你怎么看”等无信息结尾。
- 把搜索 Agent 的资料包直接粘贴成回答。

## 知乎提示词模板

```text
请把这份资料整理成一篇知乎回答。

问题：【知乎问题】
目标读者：【读者】
核心立场：【一句话】
长度：【简短 / 标准 / 深入】

要求：保持我的个人知识库风格，先认知后实战，短段落，少套话，保留必要术语和风险提醒。事实与个人判断分开。不要编造经历，不要写营销式开场和互动式结尾。
```

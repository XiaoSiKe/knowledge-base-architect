# 质量清单

交付前逐项检查。失败项应修改，不要把检查过程写进最终正文。

## 内容

- [ ] 回答了用户真正的问题。
- [ ] 核心事实来自输入资料或可靠来源。
- [ ] 事实、观点和推断没有混在一起。
- [ ] 没有虚构数字、案例、经历、引语或出处。
- [ ] 时效性信息已核实日期。

## 个人风格

- [ ] 先认知后实战，或使用更适合本主题的自然顺序。
- [ ] 一句话解释优先。
- [ ] 对小白足够通俗，同时保留必要专业词。
- [ ] 删除了重复、套话和百科式扩展。
- [ ] 没有被外部模板带成研究报告或企业文案。

## 结构与排版

- [ ] 标题层级连续，没有从一级直接跳到三级。
- [ ] 段落短，一个段落只说一个重点。
- [ ] 表格只用于比较。
- [ ] 代码块中的提示词或命令可以直接复制。
- [ ] Markdown 链接和相对路径有效。

## 实用性与安全

- [ ] 操作步骤有明确结果。
- [ ] 可由 AI 完成的复杂步骤提供了自然语言入口。
- [ ] 发布、删除、公开、付费或权限变更保留用户确认。
- [ ] 密码、Token、私钥、隐私和版权风险已处理。

## 最后删减

- [ ] 开头没有寒暄。
- [ ] 结尾没有“希望对你有帮助”等聊天残留。
- [ ] 每个章节都有新信息。
- [ ] 如果用户要求简洁，成稿已经压到完成任务所需的最短长度。

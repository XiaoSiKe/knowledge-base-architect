# 原始资料节选

GitHub 是一个非常强大且十分重要的平台。它不仅仅是一个代码托管平台，更是现代软件开发生态系统中不可或缺的一部分。GitHub 具有代码托管、项目管理、团队协作、自动化部署、开源社区交流等非常丰富的功能。

Git 是版本控制工具，GitHub 是基于 Git 的网络平台。Repository 是仓库。仓库可以保存代码。GitHub 可以保存代码，也可以协作，还可以自动部署。对于新手来说，理解这些概念是至关重要的。

Star 可以收藏项目。Fork 可以复制项目。Clone 可以把项目下载到电脑。Download ZIP 也可以下载项目。除此之外，GitHub 还有 Issue、Pull Request、Discussion、Actions、Projects、Security、Insights 等功能。

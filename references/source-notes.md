# 方法来源

本 Skill 的表达风格来自用户提供的 GitHub 知识库改稿样本。以下开源项目只用于提炼通用方法，没有复制其成稿风格或大段文本。

## 参考项目与吸收的方法

| 项目 | 许可证 | 吸收的方法 |
| --- | --- | --- |
| [Agent Skills Specification](https://agentskills.io/specification) | 开放规范 | 自包含目录、清晰触发描述、渐进披露、按需加载 references |
| [anthropics/skills](https://github.com/anthropics/skills) | 项目内分别授权 | Skill 结构、资源分层、真实任务测试 |
| [blader/humanizer](https://github.com/blader/humanizer) | MIT | 用户样本优先、保留事实、删除 AI 套话与宣传腔 |
| [mvanhorn/last30days-skill](https://github.com/mvanhorn/last30days-skill) | MIT | 多来源研究、时间边界、来源与结论对应 |
| [kepano/obsidian-skills](https://github.com/kepano/obsidian-skills) | MIT | Markdown 能力按场景拆分、平台格式与正文逻辑分离 |
| [alirezarezvani/claude-skills](https://github.com/alirezarezvani/claude-skills) | MIT | 论点、证据、推断分层；研究结果与最终写作分离 |

## 没有继承的部分

- 不继承其他 Skill 的固定口吻。
- 不把学术研究结构设为默认结构。
- 不要求每篇内容都联网或附大量引用。
- 不用复杂工具链增加小白负担。
- 不用外部质量标准覆盖用户的明确修改意见。

## 核心归属

```text
外部开源方法：增强专业能力
用户风格样本：决定最终内容
```
